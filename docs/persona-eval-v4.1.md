# 虚拟用户评测 V4.1

## 测试目的

V4.1 重点验证前台展示分和结果文案是否更适合传播。

V4 的原始分能区分用户，但偏保守；V4.1 保留原始分作为后台分析，前台展示校准后的“含活人量”。

## 展示分校准

```text
if raw_human_score <= 0.05:
  display_human_score = 18
else:
  display_human_score = clamp(round(20 + raw_human_score * 85), 20, 100)
```

噪声保护：

```text
if noise_score >= 0.70:
  display_human_score = min(display_human_score, 52)
if noise_score >= 0.50:
  display_human_score = min(display_human_score, 65)
```

解释：

- 展示分让高分用户更有成就感。
- 极低分不显示 0，避免羞辱。
- 高噪声用户不会因为“看起来很独特”被抬到过高分段。

## 展示结果

| 用户 | 原始含活人量 | 展示含活人量 | Skill 适配度 | 判断力锚点 | 主要特征 | 推荐结果文案 |
|---|---:|---:|---:|---:|---|---|
| U1 流程型 SOP 执行者 | 0 | 18 | 80 | 0 | Skill 高、正向低 | 待激活活人变量 / 优质流程资产 |
| U2 成熟协作型方法沉淀者 | 49 | 62 | 55 | 2 | 健康表达高、识边界高 | 方法沉淀型 |
| U3 复杂判断型策略人 | 73 | 82 | 39 | 5 | 锚点全中、噪声低 | 蒸不干净型 / 可教但不可替代 |
| U4 经验直觉型创作者 | 48 | 61 | 17 | 0 | 有来处高、表达低、噪声高 | 直觉有来处型 |
| U5 伪抗蒸犬儒型 | 34 | 49 | 2 | 0 | 噪声极高、表达极低 | 伪抗蒸警报 |
| U6 均衡专业 AI 放大型 | 46 | 59 | 50 | 1 | 表达高、Skill 中高、生成弱 | AI 放大型专业人 |

## V4.1 的改进

### 1. 高分更有成就感

U3 从原始 73 校准到展示 82。这个分数更接近用户对“复杂判断型高分”的直觉，也更适合分享。

### 2. 中间层能靠文案区分

U2、U4、U6 展示分分别是 62、61、59，看起来接近，但文案完全不同：

- U2：你能把经验说出来，但不会因此被完全复制。
- U4：你的直觉不是玄学，只是还没翻译完。
- U6：工具可以放大你，但不能替你判断。

这解决了“分数相近但用户不同”的问题。

### 3. 伪抗蒸不会虚高

U5 展示分为 49，进入中低分区间，但会触发“伪抗蒸警报”文案。它不会被写成“独特创作者”，而是被指出：难蒸不等于高级，有些只是还没说清。

### 4. 低分仍有台阶

U1 展示分为 18，不再是刺眼的 0。文案重点放在“稳定、清楚、好协作”，而不是“没有人味”。

## 结论

V4.1 的结果系统更适合作为产品前台：

- 主分数更有传播感。
- 组合文案能戳中不同用户。
- 高噪声机制保护了测试初心。
- 低分用户不会被羞辱。
- 中间分用户也能得到差异化解释。
