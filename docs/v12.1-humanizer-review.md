## 复核结论

### 首页、介绍与工作场景

- 删除“概念定义”“关键差异”“复杂过程”等说明书口吻，改用“能学走什么、还得谁在场”的具体问题。
- 概念页重写为“蒸馏之后 / 三层功夫 / 六面见人 / 放手之物 / 留手之物”五篇短章，不再使用定义、意义、如何理解等提纲式标题。
- 六维名称统一为“情境 / 边界 / 重构 / 审美 / 取舍 / 经验”，都用准确的二字词，不硬造新概念。
- 答题侧栏统一为“继续答题 / 答题须知 / 抗蒸小记 / 退出重测”，同级名称全部为四字。
- 工作场景明确为选填，不给个人分数加减，避免用户误以为岗位在替自己打分。

### 题目与选项

- 120 道题全部逐项核对；117 道题改写，3 道原文已经短、准、自然，审阅后保留。
- 480 个选项全部逐项核对；78 个选项做了必要的语序、主语或口语化调整。其余选项保留，是为了不把高价值选项写得更漂亮，也不损失原有区分信号。
- 114/120 道题位于 16–28 字，最长 25 字；480/480 个选项不超过 22 字。
- 逐题改写前后、选项顺序和元数据保护结果见 `docs/v12.1-copy-semantic-review.json`。

### 结果页

- 8 个段位各有独立的 `summary`、`playfulAside`、`growthNudge` 和分享短句；相邻段位不再复用同一层意思。
- 19 个标签各有独立的共鸣、误解、下一步和轻松补充，不再靠同一套空泛模板拼接。
- 主栏目统一为“判断底色 / 结果小传 / 工作映照 / 六维侧影 / 结果解读 / 分享文案”，全部为四字栏目名。
- “结果小传”同时写入段位、标签和六维高低；“结果解读”由成长建议、常见误读和本次六维表现组成，不再用四条通用提醒填充版面。
- 分享内容改成长文：包含含活人量、段位、判断底色、最高与最低维度，以及用户愿意交给 AI 和仍想留在手里的部分。
- 标签详情栏目统一为“标签释义 / 命中缘由 / 常见误读 / 可做之事 / 答题线索 / 题外一笔”；维度详情采用同样的四字体系。
- 低分段位强调稳定、可复用及当前习惯，不使用“没价值”“没判断”等羞辱性表达；高分段位提醒不要把难替代变成无法休假。
