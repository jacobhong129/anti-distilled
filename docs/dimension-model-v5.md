# 六维模型 V5

## 命名原则

V5 的六维需要比 V3 更专业，但仍然能被普通用户看懂。因此每个维度包含两个名字：

- 前台名：用户看到的短标签。
- 专业名：内部文档和结果解释使用。

## V5 六维

### 1. 情境辨识

前台短句：

> 看见任务说明之外的局。

专业定义：

识别场景、关系、时机、潜台词、利益相关者和隐含约束的能力。

测量重点：

- 是否只看字面任务。
- 是否能识别隐含期待和关系风险。
- 是否能把模糊信号转成行动判断。

与其他维度的边界：

- 情境辨识关注“局面是什么”。
- 边界校准关注“方法是否适用”。

### 2. 边界校准

前台短句：

> 知道方法什么时候会失效。

专业定义：

判断流程、模板、最佳实践、AI 建议在当前情境中是否适用，并能说明适用边界的能力。

测量重点：

- 是否迷信流程。
- 是否为了显得独特而反流程。
- 是否能提出验证、试错或边界说明。

与其他维度的边界：

- 边界校准不是原创；它判断旧方法的适用范围。
- 生成重构才是提出新问题或新方案。

### 3. 生成重构

前台短句：

> 不只选答案，还能改写问题。

专业定义：

在限制、经验和问题之间生成新表达、新方案、新问题框架的能力。

测量重点：

- 是否只能在给定选项里选择。
- 是否能把空泛需求改成可做方向。
- 是否能生成带判断的新方案，而不是模板拼贴。

与其他维度的边界：

- 生成重构关注“产生新东西”。
- 审美判别关注“判断什么更好”。

### 4. 审美判别

前台短句：

> 判断“对”之外的“好”。

专业定义：

在缺少标准答案时，对表达、方案、气质、分寸、取舍和完整性的判断能力。

测量重点：

- 是否能识别正确但无聊、专业但空心、好看但无判断。
- 是否能说出方案赢得是否漂亮。
- 是否把流畅、规范、像样误当成好。

与其他维度的边界：

- 审美判别不是“个人喜好优越感”。
- 它测的是取舍、分寸和判断痕迹。

### 5. 价值定向

前台短句：

> 不把所有判断交给目标函数。

专业定义：

面对效率、目标、压力和工具建议时，识别价值冲突并做出可表达取舍的能力。

测量重点：

- 是否只追求目标达成。
- 是否能说清冲突在哪里。
- 是否能提出替代做法，而不是只情绪化拒绝。

与其他维度的边界：

- 价值定向关注“什么不该牺牲”。
- 审美判别关注“什么更好、更有分寸”。

### 6. 经验内化

前台短句：

> 让经历长成可用的直觉。

专业定义：

将真实经历、失败、观察和长期反馈沉淀为判断模式，并能在新情境中迁移使用的能力。

测量重点：

- 判断是否有真实来处。
- 是否只是观点堆叠。
- 是否能把经验转成下一次选择的理由。

与其他维度的边界：

- 经验内化不是资历。
- 高分来自“经历变成辨别力”，不是“我见得多”。

## 辅助指标

### 可 Skill 化

衡量一个人的方法、表达、流程、产出是否容易被整理、复用和调用。

它不是负面指标。高可 Skill 化意味着清晰、稳定、好协作。

### 表达转译

原“健康表达”。衡量一个人能否把隐性判断转成他人能理解、验证、复用的语言。

它是抗蒸性的加分项，因为真正成熟的抗蒸不是说不清，而是“说得清一部分，但复制仍会损耗”。

### 伪抗蒸噪声

衡量看似不可复制、实则混乱或不稳定的选择。

它用于防止测试奖励“难搞”“神秘化”“犬儒化”。
