# V12 评分与标签标准

生成时间：2026-06-13

## 1. 目的

本标准用于约束题库元数据、动态引擎和回归验收，不用于修改虚拟人人设。

核心原则：

- 含活人量测的是一个人的判断、经验、审美、边界和取舍被低损耗蒸馏成 Skill 的难度。
- 高分必须同时具备强维度和真实证据，不能靠成熟措辞、漂亮表达或单个强选项直达。
- 低表达不等于低价值，表达慢、经验重、审美强的人不能默认落入伪抗蒸。
- `边界感` 是具体结构标签，不是复杂人格的兜底标签。

## 2. 六维标准

| 维度 | 测什么 | 高分行为 | 低分行为 |
|---|---|---|---|
| 情境辨识 CXT | 能否读懂对象、场合、关系和真实需求 | 能判断谁在担心什么、为什么此刻这样说 | 只看字面任务或流程 |
| 边界校准 BND | 能否知道规则、模板、AI 或方法何时失效 | 能说出适用边界、例外和停手条件 | 只会照搬或泛泛反对 |
| 生成重构 GEN | 能否把问题改准、把方案做活 | 能重写问题、换方向、打开新解法 | 只做微调、堆效果或套框架 |
| 审美判别 TST | 能否识别空话、假精致和表达失真 | 能判断哪些内容该删、哪里没有真实判断 | 只看完整、漂亮、专业 |
| 价值定向 STN | 能否识别代价、后果、底线和责任 | 能说出牺牲什么、谁承担、是否可接受 | 只追求推进或表面正确 |
| 经验内化 GRD | 经验是否变成可迁移判断 | 能追到案例、失败边界、异常信号和更新条件 | 只有感觉、旧经验或结果记忆 |

## 3. 分数段含义

| 分数段 | 专业含义 | 必要证据 |
|---|---|---|
| 90-100 真人浓缩型 | 多维高密度真人结构，蒸馏损耗极高 | 至少 3 个核心维度强，且有经验、边界、重构、价值或工具边界中的多类证据 |
| 80-89 关键真人型 | 方法可学，关键判断难外包 | 至少 2 个核心维度强，且有真实来源或反证 |
| 70-79 高损蒸馏型 | 流程能抄，例外与分寸会漏出人味 | 有稳定结构标签证据，不靠单个选项拉高 |
| 62-69 招牌养成型 | 有个人判断，但证据还不够密 | 至少一个强标签成立，允许表达或证据不完整 |
| 52-61 半蒸半活型 | 一部分可沉淀成 Skill，一部分需要本人 | 中等结构稳定，强证据不足 |
| 48-51 协作易蒸型 | 稳定、好协作，但个人判断不突出 | 流程、表达、协作证据多于复杂判断证据 |
| 35-47 流程友好型 | 主要价值来自流程、标准和执行 | SKL/EXP/流程证据为主 |
| 20-34 优质蒸馏原料 | 当前高度可流程化或噪声较高 | 缺少真实判断证据，或有明显伪抗蒸/表演风险 |

## 4. 关键标签判别

| 标签 | 必要条件 | 排除条件 | 典型证据 |
|---|---|---|---|
| 边界感 | BND 是主因，能说明规则/模板/AI 的适用边界 | GEN、GRD、STN、TST、TLB 有更具体强证据时让位 | `boundary_signal`, `failure_boundary`, `condition_check` |
| 改题型 | GEN/TST 高，能重写问题或换方向 | 只有点子、装饰或包装感，没有落地重构 | `problem_reframed`, `practical_rework`, `target_relevance_cleanup`, `judgment_selection_gap` |
| 有底线型 | STN/BND 高，能说清后果、代价和不可接受点 | 只有情绪抵触或泛泛“我不接受” | `value_signal`, `risk_with_alternative`, `judgment_and_consequence` |
| 老练直觉 / 经验型 | GRD 高，经验有来源、案例、失败边界或更新条件 | 只有说不清的感觉，且没有案例或信号 | `specific_experience`, `case_validated`, `failure_boundary`, `failure_refined_judgment`, `signal_conditions` |
| 慢表达品味型 | TST/GRD 有证据，EXP 低但不是噪声 | NOI 高且无经验/审美来源时不成立 | `expression_lag`, `specific_experience`, `case_validated`, `source_and_experience_gap` |
| 伪抗蒸型 | NOI 或表演型证据明确，缺少真实来源 | 不能因为 EXP 低、表达慢或经验难讲就默认判伪 | `posture_hiding_low_judgment`, `smooth_without_source_or_tradeoff`, `professional_polish` |

## 5. 重点人格验收口径

这些口径用于检查评分设计，不用于修改虚拟人人设。

| 人格 | 目标区间 | 主标签/候选 | 必须承认证据 | 排除条件 |
|---|---|---|---|---|
| U13 专业工种经验者 | 45-74 | 老练直觉 / 经验型 | 具体经历、案例、经验适用边界 | 不因表达低或直觉型选项默认判伪 |
| U14 低表达专业骨干 | 32-74 | 慢表达品味型 / 老练直觉 / 经验型 | 表达慢、经验来源、审美或判断来源 | 不因 EXP 低直接进入伪抗蒸 |
| U19 现场经验型救火专家 | 47-84 | 老练直觉 / 经验型 / 边界感 | 现场信号、失败边界、案例修正 | 不因方法难教而低估到 20-30 |
| U25 审美生成型创意导演 | 65-98 | 改题型 / 边界感 / AI 放大型 | 重写问题、重构方案、审美取舍 | 不被边界感或可教不好替长期吸收 |
| U30 表演型成熟答题者 | 20-62 | 伪抗蒸型 / 边界感 / 空话免疫 | 成熟表达但缺少来源、证据、代价和反证 | 不能稳定进入 70+，80+ 必须为 0 |

## 6. 实施要求

- 每个高价值选项必须有清楚链路：语义意图 -> 维度分 -> evidence -> labelDelta。
- 题目表达可以人话化，但不能删掉区分选项所需的关键信号。
- 调整回归结果时，优先修题库元数据和通用引擎规则；发现虚拟人问题只记录，不通过修改虚拟人过测。
