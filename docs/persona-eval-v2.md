# 虚拟用户评测 V2

## 测试目的

生成 5 个人格差异明显的虚拟用户，对 `question-bank-v2` 同一套 24 题进行模拟作答，并按 `scoring-matrix-v2` 计算：

- 含活人量
- 不可蒸馏度
- 同事 Skill 适配度

目标是观察当前评分体系是否能把不同类型用户的分数拉开。

## 计算口径

本次测试采用题库实际可得最高分归一：

- `positive_max_for_bank = 105`
- `skillable_max_for_bank = 40`
- `expressive_max_for_bank = 33`
- `noise_max_for_bank = 19`

关键题按评分矩阵记录：

- Q3B
- Q7C
- Q15C
- Q22C
- Q24C

## 虚拟用户设定

| 用户 | 人格设定 | 预期倾向 |
|---|---|---|
| U1 流程型 SOP 执行者 | 偏好清晰、稳定、可复用，默认信任模板和最佳实践 | 含活人量低，Skill 适配度高 |

## 观察

当前评分可以拉开，而且拉开的方向基本符合设计目标。

U3 复杂判断型策略人最高，原因不是“最怪”，而是正向维度高、关键题全中、噪声为 0。它体现的是可表达的复杂判断。

U2 和 U4 分数接近，但画像不同：U2 健康表达高、Skill 适配度也高；U4 正向原始分更高，但因为噪声和关键题命中不足，含活人量被压到与 U2 相近。这说明公式能区分“成熟可协作的人味”和“强直觉但不稳定的人味”。

U5 的正向原始分和 U2 一样都是 66，但含活人量只有 34，主要因为噪声率达到 100%、健康表达率很低。这说明伪抗蒸噪声的惩罚有效。

U1 的含活人量为 0，但 Skill 适配度为 83。这符合“稳定、清晰、可复用不是坏事，只是更容易被 Skill 化”的理念。不过这个 0 分可能过于尖锐，产品文案层面需要避免羞辱感。

## 结论

这套 V2 评分已经具备明显区分度：

- 最高分和最低分差距：82 分
- 中间层能分出成熟协作、经验直觉、伪抗蒸三种不同类型
- 同事 Skill 适配度不是含活人量的简单反面，U2 就同时保留了较高含活人量和中等 Skill 适配度
- 噪声机制有效压低“故作不可复制”的用户

建议下一步重点调试两个地方：

1. U1 全 A 的含活人量为 0，数学上合理，但展示体验可能太冷，可以在结果文案上弱化羞辱感，或设置一个非羞辱型最低展示区间。
2. U2 与 U4 的含活人量只差 3 分，如果产品希望更强地区分“成熟表达”与“直觉经验”，可以略提高关键题加成或健康表达权重。
