# 抗蒸性测试评分理念

## 核心定义

抗蒸性不是“不可描述”，而是“不可被低损耗复制”。

一个人真正难以被蒸馏，不是因为他说不清、混乱、任性或故作神秘，而是因为他的关键价值来自复杂情境中的判断、选择、取舍、审美、责任和经验。这些东西可以被部分描述，但很难稳定迁移成一个同事 Skill 或 agent。

因此，高分不是“无法被理解的人”，而是“可以被理解，但不能被完整替代的人”。

## 展示指标

面向用户展示三个指标：

- 含活人量：主指标，0-100%。
- 不可蒸馏度：更正式的能力指标，0-100。
- 同事 Skill 适配度：反向趣味指标，0-100%。

核心传播指标建议使用“含活人量”。

## 六个正向维度

### 1. 情境感知

能否读懂上下文、关系、时机、隐含需求、沉默和潜台词。

高分不是“想太多”，而是能识别任务说明之外真正影响结果的变量。

### 2. 审美判断

能否在没有标准答案时判断什么更好、更有味道、更成立。

高分不是“小众偏好”，而是有稳定的品味结构。

### 3. 原创生成

能否提出不是模板拼贴的新路径、新表达、新问题。

高分不是猎奇，而是能产生带判断的新东西。

### 4. 反模板能力

能否识别模板、流程、最佳实践失效的时刻。

高分不是反对流程，而是知道什么时候流程正在误导人。

### 5. 价值立场

是否有目标函数之外的判断底线。

高分不是固执，而是知道哪些东西不能为了效率牺牲。

### 6. 经验密度

判断是否来自真实经历、失败、观察和身体感，而不是只来自抽象信息。

高分不是年龄或资历，而是经验已经沉淀成辨别力。

## 两个反向维度

### 1. 可 Skill 化程度

代表工作方式稳定、外显、可复用、可预测。

它不是坏事。健康的可 Skill 化体现表达清楚、协作成熟、方法可迁移。但如果一个人的全部价值都来自稳定流程和可复制产出，就会降低含活人量。

### 2. 伪抗蒸噪声

用来惩罚看起来“不可复制”，但本质只是混乱、任性、拒绝表达、故作神秘的选项。

防止测试滑向“越怪越高分”。

## 选项分层

每题 4 个选项不做简单 0/1/2/3 递进，而对应四种认知模式：

- A 类：流程执行型。稳定、清晰、可复用，可 Skill 化较高。
- B 类：成熟协作型。懂流程，也懂边界，通常是中高分。
- C 类：复杂判断型。能识别情境、风险、隐含问题，通常高分。
- D 类：高人味或高隐性判断型。可能最高，也可能因为混乱而产生伪抗蒸噪声。

原则：D 不应该永远最高。很多题里，B 或 C 应该高于 D。

## 计分建议

每道题后台记录：

- 六维抗蒸分：每个维度 0-3。
- 可 Skill 化：0-2。
- 伪抗蒸噪声：0-2。

总分结构：

```text
含活人量 =
六维抗蒸核心分 * 70%
+ 健康表达能力 * 15%
+ 维度均衡度 * 10%
+ 关键题加成 * 5%
- 可替代惩罚
- 伪抗蒸噪声惩罚
```

其中：

- 健康表达能力来自“能沉淀方法，也知道边界”的选项，而不是所有可 Skill 化选项。
- 可替代惩罚只在可 Skill 化极高且抗蒸维度较低时触发。
- 伪抗蒸噪声用于扣除“说不清但也没有判断力”的假高分。

## 分数段

### 90-100：高密度活人

你不是不能被总结，而是一总结就损失关键判断。你的方法可以被学习，但你做选择的那部分很难被复制。

### 75-89：蒸不干净型

你有一部分能被文档化，但真正有价值的地方经常发生在边界、例外、临场和取舍里。

### 55-74：半蒸半活型

你既有稳定可复用的一面，也有一些个人判断。你不是不可替代，但也不是一个提示词就能替代。

### 35-54：同事 Skill 友好型

你的工作方式清晰、稳定、可复用。你很适合被 AI 放大，但如果不发展审美、判断和立场，也容易被 AI 复刻。

### 0-34：优质蒸馏原料

你的价值目前主要体现在流程、产出和标准执行上。这不是坏事，但你的“活人变量”还没有被充分训练出来。
