# 抗蒸性测试：最终评测设计 V6.1 清晰版

## 测试名

**抗蒸性测试：测测你的含活人量**

## 开场说明

假如有人把你的文档、聊天记录、工作习惯、产出风格，全都蒸馏成一个“同事 Skill”。

它能学走多少？又会在哪一步开始变味？

这套测试不是要证明你比 AI 高级，也不是鼓励你故作神秘。它测的是：你的判断、经验、审美和取舍，有多少很难被低损耗复制。

## 作答提示

请选择你**最常见的真实反应**，不是你觉得最正确、最体面、最高分的答案。

如果两个选项都像你，选那个更经常发生的。

有些“好蒸”也是优点，说明你稳定、清楚、好协作。

## 六个维度

- **情境辨识**：你能不能看懂话外音、关系、时机和没说出口的风险。
- **边界校准**：你知不知道流程、模板、AI 建议什么时候会失效。
- **生成重构**：你能不能把空泛需求改成一个有判断的方向。
- **审美判别**：你能不能看出“专业但空心”“正确但没取舍”的东西。
- **价值定向**：你有没有目标之外的取舍，知道什么不能轻易牺牲。
- **经验内化**：你的判断是不是从真实经历里长出来的。

## V6.1 清晰化说明

V6.1 没有继续压缩文字，而是把过短的选项补足语义。

重点修改：

- 给选项补上动作对象，比如“找参考”改成“找参考，先搭一个像样版本”。
- 给抽象判断补上含义，比如“假设过期”改成“流程背后的假设过期了”。
- 给容易误解的短句补上语境，比如“留一个具体判断”改成“删掉套话，留下一个具体判断”。
- 保留选项差异，但避免短到像标签。
