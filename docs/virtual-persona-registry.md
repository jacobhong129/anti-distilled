# 稳定虚拟人注册表：社会加权 30 人版

## 1. 用途

本文件用于固定后续每轮题库/评测游戏测试所使用的虚拟人格。

从本版开始，虚拟人不再追求“人格类型均衡互斥”，而是改成“社会加权样本池”：

- 不是每种稀缺人格都必须平均出现。
- 不是为了让每个标签都被测出来。
- 而是让虚拟人样本更接近真实社会/职场人群分布。
- 后续测试更适合观察段位集中度、标签偏置、动态出题稳定性和真实用户可能落点。

## 2. 当前稳定虚拟人总数

当前稳定虚拟人共 30 个。

后续常规测试默认使用完整 30 人组。若只做专项压力测试，可以另建专项样本，但不能替代本注册表。

## 3. 社会分布约束依据

本虚拟人池参考了几类社会/职场分布研究，而不是凭直觉平均分配：

1. 员工投入度分布：Gallup 的全球职场数据长期显示，真正高度投入者是少数，多数员工处于“未投入但正常工作”的中间状态，另有一部分主动消极者。
2. 成人技能分布：OECD PIAAC 成人技能调查显示，低到中等技能人群占相当比例，高复杂信息处理能力不是大多数人的常态。
3. 职业结构分布：BLS 职业统计显示，社会就业不是由创意/策略/专家岗位主导，办公室行政、销售、服务、生产、运输、支持类岗位占比很高。
4. AI 使用分布：工作中 AI 使用正在上升，但深度 AI 放大型用户仍不是主体；浅层提效、观望、规避和焦虑型用户都应进入样本。
5. 工作要求分布：BLS Occupational Requirements 显示，大量岗位需要在岗训练，说明“可流程化、可训练、可 Skill 化”的工作方式在真实劳动市场中非常常见。

因此，虚拟人池采用“中间厚、两端薄”的结构：

- 普通流程型、协作型、中段专业型较多。
- 高抗蒸、高生成、高边界、高价值人格较少。
- 噪声型和伪抗蒸型保留，但不放大。
- AI 放大型保留，但不假设它是大多数。

## 4. 30 人分布设计

| 人群层 | 样本数 | 占比 | 设计意图 |
|---|---:|---:|---|
| 流程/执行/可训练型 | 7 | 23.3% | 模拟真实职场中大量稳定执行、规则处理、可流程化岗位 |
| 主流协作/中段专业型 | 9 | 30.0% | 模拟最常见的中间用户：有经验、能协作，但判断和生成不极端 |
| 经验/边界/复杂判断型 | 5 | 16.7% | 保留中高抗蒸人群，但不让其占满样本 |
| AI 工具使用分层 | 3 | 10.0% | 区分深度放大型、浅层提效型、AI 焦虑规避型 |
| 生成/审美/内容判断型 | 3 | 10.0% | 保留稀缺生成和审美人格，但不平均放大 |
| 噪声/犬儒/标准答案表演型 | 3 | 10.0% | 用于检测误判和反证，但不让测试被极端样本主导 |

## 7. 后续测试记录要求

每轮虚拟人测试至少记录：

| 字段 | 说明 |
|---|---|
| persona_id | 稳定虚拟人编号 |
| social_layer | 所属社会分布层 |
| expected_result | 本注册表中的预期结果 |
| final_label | 实际标签 |
| display_score | 含活人量展示分 |
| answered_count | 实际题量 |
| followups | 触发的追问类型 |
| accuracy_judgment | 是否符合人格设定 |
| drift_note | 是否出现跨版本漂移 |

后续汇总时，不只看“每个标签有没有被测出来”，还要看：

1. 主流中段用户是否集中在合理段位。
2. 低分用户是否被区分成流程友好、待开机、空心专业、伪抗蒸。
3. 稀缺高抗蒸人格是否能被识别，但不要求它们在样本中大量出现。
4. AI 放大型是否存在识别能力，但不要求它高频出现。
5. 噪声型是否被压住，不被误判成高含活人量。
