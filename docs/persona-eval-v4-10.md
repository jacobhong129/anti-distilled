# 10 个虚拟人格评测 V4

## 测试目的

用最新的 `question-bank-v4-expanded-readable.md` 36 题和 `scoring-table-v4.csv` 后台分值，设置 10 个差异明显的虚拟人格，检验：

1. 总分是否可以分化。
2. 测试结果是否符合虚拟人格设定。

## 本轮计算口径

V4 评分表中，六个正向维度各自的最高累计值为：

| 维度 | 单维最高 |
|---|---:|
| 读空气 context | 40 |
| 识边界 boundary | 53 |
| 会生成 generative | 24 |
| 有品味 taste | 27 |
| 有立场 stance | 36 |
| 有来处 groundedness | 42 |

如果把六个单维最高直接相加，会得到 `222`。但真实用户每题只能选四个选项之一，因此单个用户实际可达到的正向总分最高是 `176`。

本轮主口径采用 `positive_max_for_bank = 176`，更符合“按题库实际最高可得分归一”的定义。旧口径 `222` 也保留在对照列，用于解释为什么旧报告里的高分偏保守。

辅助维度最高值：

| 字段 | 最高可得分 |
|---|---:|
| 可 Skill 化 skillable | 56 |
| 健康表达 expressive | 50 |
| 伪抗蒸噪声 noise | 22 |

判断力锚点：

- Q3B：写步骤，也写什么时候不能照做。
- Q7C：把“不对劲”变成一个可验证的风险。
- Q14C：做个小验证，看模板和直觉谁更接近现实。
- Q31C：说清价值冲突，并提出替代做法。
- Q36C：知道何时该用、何时不该用工具。

## 检验 1：打分是否可以分化

可以分化，但中段需要看结构维度。

从原始含活人量看，10 个用户被分成了五层：

- 极高：U3 86，U7 81。
- 高：U8 76，U10 70。
- 中高：U9 62，U2 60，U4 60，U6 57。
- 偏低但不是无价值：U5 45。
- 高度可 Skill 化：U1 0。

展示分经过校准后，分布为 18、58、68、71、71、72、80、85、89、93，更适合用户体验。

不过，U2、U4、U6、U9 的原始分集中在 57-62，说明如果结果页只显示一个“含活人量”，中段用户会显得分化不足。它们的结构差异其实很明显：

- U2 是高健康表达、高协作。
- U4 是高经验直觉、高噪声、低 Skill 适配。
- U6 是稳定专业、AI 放大型，但生成和立场较弱。
- U9 是高读空气，但有一点过度解读噪声。

因此，单一总分可以拉开极端和高低层，但中段必须配合六维画像、噪声提示和 Skill 适配度解释。

## 检验 2：测试结果是否符合虚拟人格

整体符合。

最强的验证点有三个：

1. U3、U7、U8 的高分路径不同：复杂判断、价值守门、审美生成分别被不同维度解释出来。
2. U4 与 U5 都偏 D，但 U4 仍有高来处和高生成，U5 则被 95% 噪声压低，说明系统没有简单奖励“越不像模板越高分”。
3. U1 的低含活人量和高 Skill 适配度同时出现，符合“稳定可复用不是坏事，只是更容易被 Skill 化”的设计理念。

## 主要发现

### 1. 需要修正或明确 `positive_max_for_bank`

如果沿用旧报告里的 `222`，高分人格会被压低。例如 U3：

- 用 `176` 口径：原始含活人量 86，展示分 93。
- 用 `222` 口径：原始含活人量 73。

`222` 是六个单维最高值相加，不是单个用户实际可达到的正向总分。建议在 `scoring-matrix-v4.md` 里明确：

```text
positive_max_for_bank = sum(max(option_positive_raw) for each question)
```

### 2. 中段用户需要类型化结果

U2、U4、U6、U9 的总分接近，但画像差异非常大。建议结果页除了展示含活人量，还展示一个主类型：

- 方法沉淀型：健康表达高，Skill 适配度也高。
- 直觉创作型：有来处、会生成高，但噪声高。
- AI 放大型：协作和表达高，但生成、立场不强。
- 组织雷达型：读空气高，但可能过度解读。

### 3. 噪声机制有效

U5 的正向原始分为 132，高于 U2 和 U6，但原始含活人量只有 45。这说明噪声与健康表达确实能拦住“伪抗蒸”高分。

### 4. Skill 适配度非常有解释价值

U1 的 Skill 适配度 80，U2 是 55，U4 是 17，U5 是 2。这个指标很好地解释了“能不能被整理成同事 Skill”，不应该只作为趣味副指标，建议在结果页保留。

## 结论

V4 最新题目可以支撑 10 类人格评测，且结果基本符合人格设定。

当前体系已经能分化：

- 流程型和复杂判断型能明显拉开。
- 伪抗蒸犬儒型不会被误判成高分。
- 审美生成、价值守门、现场经验、组织雷达能被不同维度识别。

当前最大问题不是题目，而是解释层：

- 总分中段略拥挤。
- `positive_max_for_bank` 需要明确用 `176` 这种真实可达口径。
- 结果页需要用“主类型 + 六维雷达 + Skill 适配度 + 噪声提示”解释，而不是只给一个含活人量百分比。
