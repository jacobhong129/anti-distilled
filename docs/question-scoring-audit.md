# 24 题计分审计表

## 审计原则

逐题检查四件事：

- 主测维度是否明确。
- 选项是否避免 A 到 D 简单递进。
- 是否把混乱、任性、拒绝表达误判为高抗蒸。
- 是否能拉开差异，而不是所有人都被引向同一个高分选项。

标记说明：

- 情境：情境感知
- 审美：审美判断
- 原创：原创生成
- 反模板：反模板能力
- 价值：价值立场
- 经验：经验密度
- Skill：可 Skill 化程度
- 噪声：伪抗蒸噪声

## 第一章：你能被写进说明书吗

### Q1 有人说要把你做成“同事 Skill”，你的第一反应是？

主测：价值、反模板。副测：Skill。

当前选项：

- A 太好了，终于有人整理我的工作流
- B 可以，但我怀疑蒸出来的东西会很难用
- C 先问一句：谁授权的？
- D 我本人都不太知道我怎么工作的

审计：

- A 体现健康可 Skill 化，不应低到 0。
- B 是成熟怀疑，抗蒸高。
- C 体现授权和边界，价值立场高。
- D 容易被误读为“神秘所以高分”，应加噪声。

建议最高：C 或 B。D 不应最高。

建议改写：

- D 改成“我本人也说不清全部过程，但我知道哪些部分不能被拿走。”这样减少纯混乱。

### Q2 如果要训练一个 AI 模仿你的工作方式，你最担心它学错什么？

主测：情境、经验。副测：审美、反模板。

当前选项：

- A 我的格式习惯
- B 我的优先级判断
- C 我什么时候会故意不按流程来
- D 我对事情“哪里不对劲”的感觉

审计：

- A 是低抗蒸、高 Skill。
- B 是成熟判断，应高。
- C 反模板高，但需要确认不是任性。
- D 情境和经验高，可作为高分。

建议最高：D。B 次高。C 视为高但略有噪声风险。

### Q3 你写工作文档时通常会：

主测：Skill 健康度、反模板。副测：经验。

当前选项：

- A 尽量写成别人照做就行
- B 写步骤，也写适用边界
- C 写到一半发现真正重要的东西很难写
- D 不太写，因为很多判断在现场才成立

审计：

- 这是测试评分理念的关键题。
- B 应为综合最高，因为它体现“可表达但知道边界”。
- C 抗蒸高，但表达成熟度不足。
- D 有现场判断，但也可能拒绝沉淀，应加噪声。

建议最高：B。C 次高。D 不应高于 B。

### Q4 同事问你“这个任务有没有标准流程”，你会说：

主测：反模板、情境。副测：Skill。

当前选项：

- A 有，我发你模板
- B 有，但先看这次场景像不像
- C 有，不过这个问题最好别完全按流程
- D 如果它真有标准流程，就不该来问我

审计：

- B 最符合成熟边界。
- C 也高，但略带预设，需要看语气。
- D 有趣但过于刻薄，容易成为装高分答案，应加噪声。

建议最高：B 或 C。D 不应最高。

建议改写：

- D 可改成“如果只靠标准流程就够，就不需要我做判断了。”更像判断，少一点抬杠。

### Q5 你最像哪种知识库条目？

主测：自我可文档化认知。副测：情境、反模板。

当前选项：

- A 可复用 SOP
- B 带风险提示的操作指南
- C 常见例外情况汇总
- D 此处需要一个活人判断

审计：

- B 是健康表达，应该高。
- C 体现经验和边界，也高。
- D 很有梗，但如果直接最高，会诱导用户选“活人判断”。

建议最高：C 或 B。D 可高但不最高，或作为关键题轻加成。

### Q6 如果 AI 接管你一天工作，最可能出问题的是：

主测：情境、价值。副测：反模板。

当前选项：

- A 基本不会，交付还挺稳定
- B 能做 70%，但会漏掉微妙优先级
- C 会把事情做得很正确，但方向不太对
- D 它会不知道什么时候该停下来

审计：

- B 情境高。
- C 反模板和价值高。
- D 价值立场高，但略抽象。

建议最高：C。D 次高。B 高。

## 第二章：你在空气里读到了什么

### Q7 会上一个方案看起来无懈可击，但你觉得不对。你会：

主测：情境、反模板。副测：经验。

当前选项：

- A 先看数据再说
- B 问几个边界问题
- C 试着指出它“太顺了”的地方
- D 观察谁在沉默，以及为什么沉默

审计：

- A 是理性但偏常规，不应低分。
- B 是成熟高分。
- C 很好，但“太顺了”需要转化成可讨论问题。
- D 情境感强，但如果只观察不行动，可能虚。

建议最高：B 或 C。D 高但不必最高。

### Q8 别人发来一句“你方便再看看吗”，你通常会理解为：

主测：情境。

当前选项：

- A 他真的只是想让我看看
- B 可能有问题，但不想明说
- C 他需要我背锅或兜底
- D 先看上下文、关系和时间点

审计：

- D 明显成熟最高。
- C 容易显得犬儒，不应高。
- B 合理但略推测。

建议最高：D。C 加噪声或低于 B。

### Q9 一个新人照着文档做错了，你更倾向于判断：

主测：情境、经验。副测：Skill 健康度。

当前选项：

- A 文档没写清楚
- B 新人没理解关键前提
- C 这件事本来就不该只靠文档
- D 我想知道他为什么会按那个方向理解

审计：

- D 最成熟，因为它寻找理解路径。
- A 和 B 都可能片面归因。
- C 有道理，但可能过早否定文档。

建议最高：D。C 次高。A/B 中等。

### Q10 当所有人都说“先快速推进”时，你会：

主测：反模板、价值。副测：情境。

当前选项：

- A 同意，速度重要
- B 问清楚快速推进的代价
- C 找出那个没人愿意说的风险
- D 看这是不是一种集体逃避

审计：

- B 是成熟高分。
- C 高，但可能过度风险化。
- D 很深，但也可能心理化过度。

建议最高：B。C/D 高但需控制噪声。

### Q11 你判断一个人靠谱不靠谱，主要看：

主测：经验、情境。

当前选项：

- A 交付是否稳定
- B 关键时刻是否能兜住
- C 他怎么处理模糊和冲突
- D 他在没人要求时会不会多想一步

审计：

- A 是基础可靠，不应低。
- C 是复杂判断最高。
- D 很有活人味，但可能偏自驱，不一定等于可靠。

建议最高：C。B/D 高。A 中等。

### Q12 遇到模糊任务，你第一步通常是：

主测：情境、反模板。

当前选项：

- A 拆任务、列步骤
- B 确认目标和限制
- C 找真正的决策者和隐含期待
- D 先判断这个任务是不是问错了

审计：

- B 是成熟协作高分。
- C 情境高。
- D 反模板高，但如果每次都先质疑任务，可能噪声。

建议最高：C 或 B。D 高但不稳定。

## 第三章：你会不会背叛模板

### Q13 你看到一篇非常标准、非常流畅、非常像 AI 写的文章，会觉得：

主测：审美、反模板。

当前选项：

- A 挺好，效率高
- B 能用，但没什么记忆点
- C 它最大的问题是没有犯任何有趣的错
- D 我想知道作者本人到底在哪里

审计：

- B 是清楚的审美判断。
- C 有趣，但“有趣的错”可能过度文艺。
- D 很贴题，但略像标准高分答案。

建议最高：B 或 D。C 可高但需避免装腔。

建议改写：

- C 改成“它没有冒险，所以也没有真正的判断。”更准确。

- 或将 Q24 改成结果页前的价值题，不计入主分，只用于文案调性。

## 全局审计结论

当前题库气质成立，但存在三类问题：

### 1. D 选项诱导过强

多道题的 D 选项都像“最有活人味”的标准答案，用户容易学会选 D。需要让 B/C 在更多题中成为最高分。

### 2. 原创生成维度不足

第 13-18 题主要在测识别模板感和审美判断，真正的原创生成题偏少。建议新增或改写 2-3 题，让用户在方案、表达、问题重构中做选择。

### 3. 伪抗蒸噪声需要写进题目

“说不清”“不按流程”“不舒服”“不是模板”都不应自动高分。选项需要体现：如果能把隐性判断转化为可讨论的边界，才是高抗蒸。

## 建议的下一步

1. 重写第 1、4、5、13、14、17、19、24 题，降低诱导性。
2. 增加原创生成相关的选择题，替换 1-2 道重复的情境题。
3. 给每道题建立正式选项分值表。
4. 用 3 个虚拟用户画像试跑：流程型、混乱型、复杂判断型，检查分数是否分化。
