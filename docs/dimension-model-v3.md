# 六维模型 V3

## 改版原因

V2 的六维中，“原创生成”和“反模板能力”容易被用户理解成同一件事：不按套路、能想新东西。为了降低理解成本，V3 将维度改成更口语、更独立的六个面向。

核心原则：

- 用户一眼能看懂每一维在说什么。
- 每一维回答一个不同问题。
- 维度之间可以相关，但不要同义。
- 结果页展示时不使用太学术的词。

## V3 六维

### 1. 读空气

原维度：情境感知。

定义：能不能读懂场景、关系、时机、潜台词和真正的需求。

它回答的问题：你是不是只看任务说明，还是能看见任务背后的局面？

高分表现：

- 会看上下文再行动。
- 能识别谁在沉默、谁在犹豫、谁真正关心什么。
- 能发现“话是这么说，但事不是这么回事”。

低分表现：

- 只按字面意思执行。
- 忽略关系、时机和隐含目标。

### 2. 识边界

原维度：反模板能力。

定义：知道流程、模板、最佳实践什么时候有效，什么时候失效。

它回答的问题：你是不是会被模板带着跑，还是知道模板的适用范围？

高分表现：

- 不盲目反流程，也不迷信流程。
- 能说出“这套方法在什么条件下不成立”。
- 能把不对劲的直觉转成可讨论的问题。

低分表现：

- 只会照模板。
- 或者为了显得独特而反对模板。

与“会生成”的区别：

- 识边界是判断旧框架哪里不够。
- 会生成是提出新的表达、方案或问题。

### 3. 会生成

原维度：原创生成。

定义：能不能从经验、问题和限制中长出新的表达、方案、角度。

它回答的问题：你是不是只会选择现成答案，还是能产生新东西？

高分表现：

- 能重构问题。
- 能提出带判断的新方案。
- 能把真实经验转化成表达或创意。

低分表现：

- 只做模板拼贴。
- 只在已有选项里挑一个。

与“有品味”的区别：

- 会生成偏“产出新的东西”。
- 有品味偏“判断什么东西更好”。

### 4. 有品味

原维度：审美判断。

定义：在没有标准答案时，能不能判断什么更好、更准、更有味道。

它回答的问题：你有没有自己的判断口味，而不是只追求正确、流畅、专业？

高分表现：

- 能看出“正确但无聊”。
- 能判断方案的气质、分寸、代价。
- 能说出好在哪里、差在哪里。

低分表现：

- 只看是否规范、漂亮、流畅。
- 把“像模板”误认为“专业”。

### 5. 有立场

原维度：价值立场。

定义：面对效率、目标、压力时，是否知道哪些东西不能轻易牺牲。

它回答的问题：你是不是只有目标函数，还是有自己的取舍原则？

高分表现：

- 能说出价值冲突在哪里。
- 能提出替代做法，而不是只喊反对。
- 知道什么时候该慢下来。

低分表现：

- 只要达成目标就行。
- 或者只有情绪化拒绝，没有可协商的表达。

### 6. 有来处

原维度：经验密度。

定义：你的判断是否来自真实经历、失败、观察和长期沉淀。

它回答的问题：你的判断是信息拼出来的，还是经历长出来的？

高分表现：

- 能从过去的真实场景中提炼判断。
- 有敏感点，也知道敏感点的来源。
- 能解释自己为什么会这样判断。

低分表现：

- 只有观点，没有来处。
- 只有经历，但没有沉淀成判断。

## 结果页展示建议

结果页不直接展示学术化维度，展示以下短标签：

- 读空气
- 识边界
- 会生成
- 有品味
- 有立场
- 有来处

每个标签配一句解释：

- 读空气：你能不能看见任务说明之外的东西。
- 识边界：你知不知道模板什么时候会失效。
- 会生成：你能不能长出新想法，而不只是选答案。
- 有品味：你能不能判断什么更好，而不只是更标准。
- 有立场：你有没有目标函数之外的取舍。
- 有来处：你的判断是不是从真实经历里长出来的。
