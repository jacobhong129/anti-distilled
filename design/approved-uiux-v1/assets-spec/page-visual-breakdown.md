# 逐页视觉元素拆解

本文件按页面拆解视觉元素，供后续资产生成、前端组件拆分和截图验收使用。

开发阶段必须同时满足两件事：页面结构正确，视觉资产正确。蒸馏瓶、人像、烟雾、徽章、标签等关键视觉元素不得用 CSS 简笔画、emoji、占位图或普通渐变替代。

## 全局规则

### 全局视觉层级

每个页面按以下层级拆分，开发时也按这个顺序组织：

1. `PageShell`：页面尺寸、最大宽度、安全区、桌面横向画布、移动端竖向重排。
2. `SmokeLayer`：背景烟雾、边缘烟雾、结果烟雾，不参与排版，不遮挡阅读。
3. `ArtLayer`：蒸馏瓶、人像、输出卡、徽章等正式美术资产。
4. `NativeUILayer`：标题、正文、按钮、表单、进度点、卡片、抽屉、底部弹窗。
5. `StateLayer`：选中、禁用、返回、复制成功、抽屉打开、accordion 展开等交互状态。

### 桌面端

- 使用横向大画布。
- 视觉叙事可以左右展开。
- 可使用侧边栏、右侧抽屉、横向卡片组。
- 不得把移动端单列布局放大到桌面端。

### 移动端

- 必须重排为竖向阅读/操作流。
- 不得直接缩放桌面端。
- 关键内容优先级：标题/状态 -> 主任务 -> 可选解释 -> 次级控件。
- 烟雾必须存在，但不能遮挡题目、选项、表单和结果。

### 烟雾语义

- 彩色烟雾：人的判断、经验、审美、取舍、场景感、不可低损耗复制的人味。
- 灰色烟雾：被流程化、标准化、工具化、模板化的部分。
- 答题页烟雾：动态追问强度和当前路径的复杂度。
- 结果页烟雾：含活人量百分比的可视化。分数越高，彩色成分越多；分数越低，灰度和规整感越强。

## 01 首页

参考图：[01-home.png](../images/01-home.png)

### 页面目标

让用户第一眼理解本产品在测什么：人的想法、判断、经验和取舍经过蒸馏，可能被转成工作流、插件、Skill 和提示词；抗蒸性测的是这个过程里还剩多少不可低损耗复制的人味。

### 关键视觉元素

| 元素 | 类型 | 实现方式 | 状态 |
| --- | --- | --- | --- |
| 品牌图标 | SVG / CSS | 可用 SVG，需保持蒸馏瓶形态 | 待实现 |
| 首页彩色烟雾背景 | 图片资产 | `smoke-home-ambient`，桌面/移动可共用裁切 | 已完成 |
| 蒸馏因果链插画 | 图片资产 | 已生成桌面/移动 | 已有 |
| 主标题 | 代码文本 | 宋体/书卷感，桌面大字，移动重排 | 待实现 |
| 主 CTA | 代码按钮 | 绿色实心，箭头图标 | 待实现 |
| “什么是抗蒸性”入口 | 代码链接 | 文字链接/轻按钮 | 待实现 |
| 底部含活人量说明卡 | 代码组件 + SVG 印章 | 星芒必须居中；印章不可挤压正文 | 待实现 |

### 桌面端布局

- 顶部横向 header。
- 主标题居中或左中偏上。
- 蒸馏因果链横向展开：人像 -> 蒸馏瓶 -> 工作流/插件/Skill/提示词。
- 底部说明卡横跨主要内容区。

### 移动端布局

- Header 简化为品牌 + 菜单。
- 标题和 CTA 在首屏上部。
- 因果链使用 `home-distillation-mobile.png`，竖向展示。
- 说明卡位于下方，不挤压印章。

### 禁止替代

- 不得用 CSS 简笔蒸馏瓶。
- 不得用圆形头肩图替代人像。
- 不得用渐变光斑替代彩色烟雾。
- 不得把 `home-distillation-desktop.png` 强行缩小作为移动端插画；移动端必须使用 `home-distillation-mobile.png`。

## 02 什么是抗蒸性

参考图：[02-what-is-anti-distilled.png](../images/02-what-is-anti-distilled.png)

### 页面目标

专业解释“抗蒸性”的概念、理论模型、六个观测维度和培养方法，增强可信度。

这一页不承担搞笑表达，语言应更像一份轻量理论说明：把“人被蒸馏成 Skill”的梗解释为复杂工作判断被抽取、压缩、规训和可复制化的过程。

### 关键视觉元素

| 元素 | 类型 | 实现方式 | 状态 |
| --- | --- | --- | --- |
| 标题区烟雾 | 图片资产 | 低饱和青灰烟雾，边缘出现 | 已完成 |
| 概念定义卡 | 代码组件 | 文本卡，轻边框 | 待实现 |
| 三层模型图 | SVG / CSS | 行为层、判断层、责任层三层图 | 待实现 |
| 六维图标 | SVG 图标组 | 六个统一风格图标 | 已完成 |
| 培养方法图标 | SVG 图标 | 可从六维图标组和标签图标派生 | 已完成 |
| 底部免责声明 | 代码组件 | 淡色信息条 | 待实现 |

### 桌面端布局

- 横向大画布，内容卡片分区。
- 顶部标题居中。
- 第一行：概念定义 + 三层模型。
- 第二行：六维观察维度。
- 第三行：为什么重要 + 如何培养。

### 移动端布局

- 竖向知识卡。
- 三层模型变成竖向 stacked chips。
- 六维图标用两列网格。
- 底部按钮固定或贴近内容末尾。

### 内容结构

- 概念定义：从人到 Skill 的信息损耗。
- 三层模型：行为层、判断层、责任层。
- 六个观测维度：情境辨识、边界校准、生成重构、审美判别、价值定向、经验内化。
- 为什么重要：AI 能复制输出，但更难复制现场理解、价值取舍和后果承担。
- 如何培养：积累可追溯经验、练习边界判断、把隐性判断表达出来。

参考图：[03-work-context.png](../images/03-work-context.png)

### 页面目标

用户开始测评后，可选择校准工作场景，也可以跳过。工作场景不改变个人含活人量，只影响岗位蒸馏度解释。

| 元素 | 类型 | 实现方式 | 状态 |
| --- | --- | --- | --- |
| Stepper | 代码组件 | 4 步，当前为工作场景 | 待实现 |
| 边缘烟雾 | 图片资产 | 青灰/灰烟，低干扰 | 已完成 |
| 表单大卡 | 代码组件 | 白色卡片，轻阴影 | 待实现 |
| 问题组图标 | SVG 图标 | 工作包、协作、人群、滑杆 | 已完成 |
| 单选项 | 原生表单 + 样式 | 桌面横排，移动竖排 | 待实现 |
| 跳过说明 | 代码组件 | 信息提示条 | 待实现 |

### 桌面端布局

- 顶部横向 stepper。
- 标题居中。
- 表单卡置中，三组问题横向展开。
- 底部双按钮：填写 / 跳过。

### 移动端布局

- Stepper 压缩。
- 每个问题独立卡片。
- 单选项竖排。
- 按钮全宽。

### 状态要求

- 未填写时，“填写，约 20 秒”可点击但提交后需要提示至少选择必填项。
- 选择后，radio 与文字都应有明确选中状态。
- 跳过后仍进入动态测试，但结果页不显示岗位蒸馏度卡。
- 跳过说明必须解释：个人含活人量不受影响，只少一个岗位语境解释。

## 04 动态答题

参考图：

- [04-question-desktop-mobile.png](../images/04-question-desktop-mobile.png)

### 页面目标

承载核心动态测试。用户需要清楚知道当前追问阶段、已完成数量、当前题目和选项；可返回上一题。

### 关键视觉元素

| 元素 | 类型 | 实现方式 | 状态 |
| --- | --- | --- | --- |
| 桌面侧边栏 | 代码组件 | 品牌 + 导航 + 退出提示 | 待实现 |
| 阶段标题 | 代码文本 | 紫色当前阶段，例如“正在追问边界” | 待实现 |
| 进度点 | 代码组件 | 圆点进度，不能用普通进度条替代 | 待实现 |
| 答题卡 | 代码组件 | 大白卡，桌面宽行阅读 | 待实现 |
| 选项卡 | 代码组件 | 未选/选中/禁用状态 | 待实现 |
| 选中勾 | SVG / CSS | 紫色圆形勾 | 待实现 |
| 移动端边缘烟雾 | 图片资产 | `smoke-question-mobile` | 已完成 |
| 烟雾浓度控件 | 代码组件 + 烟雾资产 | 底部烟雾 slider | 待实现 |

### 桌面端布局

- 左侧侧边栏。
- 中央大答题卡。
- 问题文本必须保持阅读宽度，不能过大导致一行很少字。
- 选项卡纵向排列，选中态明确。

### 移动端布局

- 单列，无侧边栏。
- Header：返回、阶段标题、菜单。
- 进度点位于题目前。
- 选项卡全宽。
- 移动端无 hover 态；未选项不得显示紫色边框。
- 底部烟雾浓度控件可见。

### 状态要求

- 未选状态：白底、浅边框、无紫色描边、无勾。
- 选中状态：淡紫底、紫色边框、右侧勾。
- 跳题/切题动画期间：选项短暂 disabled，防止连续误触。
- 返回上一题：恢复上一题已选项，但不能把该状态误带到下一题。
- 桌面端可以有 hover；移动端必须禁用 hover 风格。

## 05 结果总览

参考图：[05-result-overview.png](../images/05-result-overview.png)

### 页面目标

展示含活人量、段位、结构标签、岗位蒸馏度、六维表现和判断依据。结果页必须有趣、有记忆点，同时避免信息过度拥挤。

### 关键视觉元素

| 元素 | 类型 | 实现方式 | 状态 |
| --- | --- | --- | --- |
| 分数烟雾 | 图片资产 | 根据含活人量高/中/低切换 | 已完成 |
| 分数数字 | 代码文本 + 渐变 | 高分彩色渐变，低分灰渐变 | 待实现 |
| 段位徽章 | 图片资产 | 每个段位独立徽章 | 已完成 |
| 结构标签徽章 | 图片资产 | 覆盖 19 个正式标签和补充标签 | 已完成 |
| 六维进度条 | 代码组件 | 彩色进度条，iOS 不得蓝化 | 待实现 |
| 分享文案卡 | 代码组件 | 可复制 | 待实现 |
| 岗位蒸馏度卡 | 代码组件 | 仅填写工作场景后显示 | 待实现 |
| 烟雾图例 | 代码组件 + 小烟雾资产 | 灰 -> 单色 -> 多色 | 待实现 |

### 桌面端布局

- 结果 hero 横向：左分数，右段位。
- 下方卡片区：结构标签、分享、岗位蒸馏度、六维、依据。
- 可以有高低分对比用于设计稿，但真实页面只展示用户本人结果。

### 移动端布局

- 分数和段位优先。
- 卡片纵向排列。
- 六维列表可点击。
- 底部说明尽量短，不要把专业说明塞满结果页。

### 结果烟雾映射

| 含活人量 | 烟雾表现 |
| --- | --- |
| 80% 以上 | 多色、丰富、有机、较浓 |
| 60%-79% | 彩色适中，灰烟开始出现 |
| 40%-59% | 彩色较弱，灰烟明显 |
| 20%-39% | 以灰烟为主，少量弱色 |
| 20% 以下 | 灰度、规整、低彩度 |

### 状态要求

- 分数单位统一为 `%`。
- 不出现版本号、题库版本、测试参数。
- 六维条必须是自定义颜色，不得在 iOS 上显示成默认蓝色链接/控件色。
- 结果页的趣味性优先放在段位说明、标签解释和分享文案中，不再堆放过多理论说明。
- “这套测试在看什么”“烟雾颜色说明”等长说明默认不放在结果页主体，可挪到“什么是抗蒸性”或详情中。

## 截图验收要求

开发每完成一个页面，至少保留两张对照截图：

- 桌面端：建议 `1440x1000` 或接近真实宽屏。
- 移动端：建议 `390x844` 或 iPhone 常见比例。

每张截图按以下顺序检查：

1. 是否使用了正确的正式资产，而不是近似代码图形。
2. 桌面端是否是横向大画布，移动端是否真正重排。
3. 烟雾是否存在，并符合页面语义。
4. 标题、正文、按钮和卡片是否无挤压、无遮挡、无异常留白。
5. 交互状态是否符合本文件要求。

## 页面级资产优先级

1. 首页蒸馏因果链：已完成。
2. 烟雾组：必须优先完成，因为首页、答题、结果、详情都依赖。
3. 结果徽章组：结果页识别度核心。
4. 结构标签徽章：结果页和详情页共用。
5. 六维图标：说明页、结果页、详情页共用。
6. 工作场景和答题页图标：可用统一 SVG 线性图标实现。
