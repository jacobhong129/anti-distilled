# 视觉说明

## 产品气质

抗蒸性测试是一个面向外部用户的中文评测产品。它可以有梗，但整体必须像一个完整、可信、可交付的产品，而不是测试页面或玩具页面。

视觉关键词：

- 中文书卷感
- 蒸馏实验隐喻
- 低饱和度彩色烟雾
- 白纸/宣纸质感
- 轻边框、轻阴影
- 专业说明与有趣结果并存

## 烟雾规则

烟雾是本产品最重要的视觉语义，不是背景装饰。

- 彩色烟雾：代表含活人量、人的判断、经验、审美、取舍、场景感，以及不可低损耗复制的人味。
- 灰色烟雾：代表被流程化、标准化、工具化、模板化的部分。
- 规整烟雾：代表更容易被复制、被封装、被交给流程或 AI 执行。
- 结果页烟雾必须随含活人量变化：含活人量越高，彩色成分越多；含活人量越低，灰色成分越多。
- 答题页烟雾代表动态追问强度，可出现在页面边缘、进度区域、底部烟雾浓度控件，但不得压正文。

## 首页因果链

首页必须清晰表达：

```text
人的想法 / 判断 / 经验 / 取舍
  -> 蒸馏过程
  -> 规则 / 工作流 / 提示词 / 插件
  -> 工作流 / 插件 / Skill / 自动化功能
```

蒸馏瓶、输出卡片和烟雾流向必须服务这个逻辑。不能只把蒸馏瓶当作装饰物。

## 字体

建议开发字体栈：

```css
--font-title: "Songti SC", "STSong", "SimSun", serif;
--font-body: "Kaiti SC", "KaiTi", "Songti SC", "STSong", serif;
--font-ui: "PingFang SC", "Microsoft YaHei", system-ui, sans-serif;
```

使用规则：

- 大标题优先使用宋体/书卷感 Serif。
- 正文可使用宋体或楷体气质字体，保证中文阅读舒适。
- 控件、数字、标签可以使用系统 UI 字体，但不得出现浏览器默认字体感。
- 移动端也要尽量保持宋体/楷体气质，不能全部落成黑体。

## 色彩

基础色：

- 墨黑：`#101816`
- 纸白：`#fbfaf3`
- 主绿：`#0b6a4f`
- 弱绿：`#80b9aa`
- 紫色选中态：`#6a54c8`
- 珊瑚烟雾：`#e39183`
- 琥珀强调：`#e1a34f`
- 低分灰烟：`#8d9292`

结果页颜色：

- 高含活人量：紫、青绿、珊瑚、琥珀共同出现。
- 中等含活人量：彩色减少，灰色增加。
- 低含活人量：以灰色为主，只保留少量弱紫或弱青。

## 布局规则

桌面端：

- 横向大画布。
- 宽屏优先，内容区域应充分利用横向空间。
- 页面可以有左右结构、侧边导航、右侧抽屉。

移动端：

- 重新排版，不缩放桌面端。
- 单列优先。
- 题目、选项、按钮必须贴合安全宽度，不出现右侧留白。
- 结果详情使用底部弹窗，不使用桌面右侧抽屉。

## 交互规则

- 移动端不设计 hover 态。
- 答题页只有真实选中态，不出现“看起来像已选中”的默认描边。
- 答题页支持返回上一题。
- 工作场景校准可以跳过，且要说明跳过不影响个人含活人量，只影响岗位蒸馏度解释。
- 结构标签和六维进度条可点击，打开详情解释。
